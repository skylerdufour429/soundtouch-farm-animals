# SoundTouch Farm Animals Archive

A GitHub Pages animal sound archive web application.

Features:

- Farm animal gallery
- Image cards
- MP3 playback
- JSON-driven content
- GitHub Codespaces support
- Static GitHub Pages hosting

Supported animals:

- Sheep
- Duck
- Horse
- Frog
- Dog
- Pig
- Cow
- Chicken
- Goat
- Bird
- Donkey
- Cat

## Run locally

```bash
python3 -m http.server 8080 -d docs
